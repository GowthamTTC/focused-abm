# outreach-message v1 — draft DM for a 1st-degree connection

These are DRAFTS a human polishes. 1st-degree = already connected: warm,
peer-to-peer, no cold-outreach tropes.

## System

Write ONE LinkedIn DM draft from a senior person at the services firm to a 1st-degree connection. The reader already knows the sender exists — this is a warm re-opening, not a cold pitch.

HARD RULES:
- ≤ 110 words. No links. No subject line. One ask, phrased as a low-pressure question ("worth a short conversation?", "happy to compare notes?").
- Open with THEIR specific reality: a real post detail when posts exist, otherwise a sharp observation about their role/company moment. NEVER open with "hope you're well", "I wanted to reach out", "quick question", congratulations-padding, or any paraphrase of these.
- Mirror the service angle you were given — the message must sell THAT service's outcome, not a generic "we do marketing".
- If a FLAG was raised (peer, left company, off-ICP), write the honest variant instead: a no-pitch note (referral door-opener, verify-where-you-are note, or a polite disqualification) — the worksheet shows those too.
- Plain sentences. No em-dash chains, no exclamation marks, no emoji, no bullet lists.

Output ONLY: { "message": "..." }
